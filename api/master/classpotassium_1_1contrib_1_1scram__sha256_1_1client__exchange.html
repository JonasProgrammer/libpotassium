Detailed Description

Client-side SCRAM-SHA-256 or SCRAM-SHA-256-PLUS exchange using the authentication identity for authorization.

Call start(), respond(), then finish(). Any failed or out-of-order operation closes the exchange. A successful finish() also closes it. Call reset() before using it again.
