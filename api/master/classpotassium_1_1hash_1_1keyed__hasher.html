Detailed Description

template<keyed_hash_algorithm A, class Storage = typename keyed_hash_traits<A>::default_storage>
requires hash_state_storage<Storage, typename keyed_hash_traits<A>::state_type>
class potassium::hash::keyed_hasher< A, Storage >

Incremental keyed BLAKE2b or HMAC with guarded state by default.

Template Parameters
AKeyed digest algorithm, such as auth::hmac_sha256 or blake2b<>.
StorageState owner, such as guarded_hash_state or inplace_hash_state.

Finalization consumes the stream and immediately wipes its state. Use finalize_for_reuse() to retain a token for allocation-free reset.
