Detailed Description

Move-only guard for a lock on caller-owned memory. Disjoint byte ranges can share a page and its lock.

import potassium.core;
import std;
int main()
{
potassium::init();
constexpr std::size_t size = 32;
auto buffer = std::make_unique<std::byte[]>(size);
potassium::mlock_guard guard{buffer.get(), size};
// Read sensitive data directly into buffer and use it here.
}

◆ mlock_guard()

potassium::mlock_guard::mlock_guard ( void * address,
std::size_t len )

Locks a region of writable memory.

Precondition
address is non-null and points to a writable region of at least len bytes.
len is greater than zero.
The region remains alive, writable, and at the same address until the lock is released.
The guard has exclusive control of locking on every page touched by the region.
Exceptions
std::runtime_errorIf libsodium reports that the lock failed.

◆ ~mlock_guard()
