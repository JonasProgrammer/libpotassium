Detailed Description

HMAC algorithms, typed keys, and one-shot message authentication.

Choose potassium::auth::hmac_sha256, potassium::auth::hmac_sha512, or potassium::auth::hmac_sha512256 (the default). Use potassium::hash::keyed_hasher for incremental messages.
