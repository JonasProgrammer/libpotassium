Detailed Description

Seal and open messages using a local private key and a peer public key.

See also
potassium::box::curve25519xsalsa20poly1305, potassium::box::curve25519xchacha20poly1305

For repeated messages with one peer, use precompute once and pass the shared key to seal or open. Establish the peer's identity before using its public key. Both participants can produce valid ciphertext and derive the same key in either direction. Coordinate explicit nonces across both directions, or let seal generate a random nonce. Static key pairs provide no forward secrecy after private-key compromise.
