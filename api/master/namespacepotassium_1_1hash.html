Detailed Description

Digest algorithms, one-shot hashes, and reusable keyed and unkeyed streams.

Unkeyed choices include potassium::hash::blake2b, potassium::hash::sha256, potassium::hash::sha512, potassium::hash::sha3_256, and potassium::hash::sha3_512. Keyed streams support BLAKE2b and the HMAC algorithms in potassium::auth.
