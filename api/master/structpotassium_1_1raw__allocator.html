Detailed Description

Guarded heap storage for sensitive data. Libsodium attempts to lock pages and wipes the storage on release. Each allocation has page-level overhead. For page-backed allocations, a byte count divisible by the required alignment gives an aligned address when the alignment also divides the page size.
